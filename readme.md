# Goofy Captcha

Goofy Captcha is a simple website made for the **Bad UI** category.

The goal is to make a captcha that works but has intentionally confusing and funny UI

## Features

* Simple captcha question
* Misleading buttons
* Button that moves away from the mouse
* Fake loading bar
* Funny messages
* Basic HTML, CSS, and javascript

## How to Run

1. Download the files.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser.
